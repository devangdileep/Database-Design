Project Title
: ShopSphere: A Relational Database Management System for a Multi-Vendor Online Shopping Platform
2.1. Functional requirements:
  • 1.Multi-Role Navigation: Switch between Customer Storefront, Vendor Dashboard, Admin Portal, and Cart & Atomic Checkout.
  • 2.Multi-Vendor Catalogue & Autocomplete Search: Product search with autocomplete, category pills, and multi-criteria filters.
  • 3.Vendor Inventory & Order Fulfillment: Real-time inventory table with automated low-stock trigger alerts and order fulfillment queue.
2.2. Non functional requirements:
  • 1.Responsiveness & Layout: Mobile-first flexible CSS Grid layout with left sidebar, top search capsule, and bottom dock.
  • 2.Design Aesthetic: Dark Glassmorphism canvas, backdrop blur, electric blue accents.
  • 3.Reactivity & Micro-animations: Smooth Framer Motion card lift effects and button micro-feedback.
